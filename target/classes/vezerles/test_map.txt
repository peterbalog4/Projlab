# ═══════════════════════════════════════════════════════════════
# Szabad elrendezésű térkép – "Bízz bennem, mérnök leszek"
# ═══════════════════════════════════════════════════════════════
#
# FORMÁTUM:
#
#   node <id> <x> <y>
#       Egy csomópontot (kereszteződést vagy végpontot) definiál
#       pixelkoordinátákkal. Az utak ezek között húzódnak.
#
#   road <id> <savokA> <savokB> <nodeA_id> <nodeB_id>
#       Létrehoz egy utat a két csomópont között.
#       A hossz és az irány automatikusan kiszámítódik.
#       Csak vízszintes vagy függőleges utak támogatottak.
#
#   depot <id> <node_id> <jmf>
#       Telephely egy adott csomópontnál.
#
# ── PÉLDA TÉRKÉP ────────────────────────────────────────────────
#
#   n0 ── r0 ── n1 ── r1 ── n2
#   |            |            |
#   r2           r3           r4
#   |            |            |
#   n3 ── r5 ── n4 ── r6 ── n5
#
# ════════════════════════════════════════════════════════════════

# Csomópontok (x, y pixelkoordinátákkal)
node n0   50   50
node n1  410   50
node n2  770   50
node n3   50  410
node n4  410  410
node n5  770  410

# Utak: road <id> <savokA> <savokB> <nodeA> <nodeB>
road r0  2 2  n0 n1
road r1  2 2  n1 n2
road r2  2 2  n0 n3
road r3  2 2  n1 n4
road r4  2 2  n2 n5
road r5  2 2  n3 n4
road r6  2 2  n4 n5

# Telephely
depot d0  n0  5000
